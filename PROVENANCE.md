# Provenance

This repository is a clean release snapshot with a new, independent Git
history. The maintainers preserve the non-public development history
separately; it is not part of this repository.

The design was informed by memory-injection and cooldown concepts in
[ellmos-ai/bach](https://github.com/ellmos-ai/bach), an MIT-licensed project.
No BACH source file, database, operator configuration, or internal reference
document is bundled here. The reserved BACH backend is an unavailable,
fail-open adapter and does not access BACH data.

The copyright and permission notice applicable to this package is retained in
[LICENSE](LICENSE).
